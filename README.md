# App Academy React Vite Template

This repo contains a basic Vite React template configured for use in App Academy
projects.

## How to clone

To clone this repo as `new_project_name`, run

```shell
npx degit tx00-web/vite-testing-template#main new_project_name
```

in the directory where you want the new project to appear.

## How to install and run

Once the repo is cloned, run 
- `git init`.
- `cd <new-project-name> && npm install` to install dependencies. 
- To run the app, type `npm run dev` in the root directory.
- To run the tests, type `npm test` in the root directory.
  
## Reminder

Don't forget to update this README, change the `title` in __index.html__, and change the `"name"` in __package.json__ when making a new project!
